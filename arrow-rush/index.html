2. 특수블록 / HELL

기본·∞ 모드 특수블록은 화살표 최대 2개까지만 합쳐집니다.

←■→HELL 전용

3. 스핀스핀~

PERFECT 50개 → GOGOGO 10초. 특수블록만 떨어집니다.

특수블록 성공 10개 → SPECIAL TIME. 두 번 입력, 점수 ×5, 블록 10개가 나오면 종료합니다.

둘이 겹치면 스핀스핀~이 발동합니다. 10초 동안 실제 중앙 레인 전체가 시계방향으로 한 바퀴 돌며 단일 화살표만 나옵니다. 스핀 중에도 MISS·라이프·쉴드는 평소 규칙 그대로지만 판정 성공 범위는 평소의 1.5배로 넓어집니다. 스핀이 끝나면 GOGOGO·SPECIAL 게이지와 진행상태는 모두 0으로 초기화됩니다.

4. CTRL 블록 파괴

블록 10개 성공할 때마다 CTRL 1개, 최대 4개 저장. Ctrl을 누르면 1개를 써서 판정선에 가장 가까운 블록 1개를 즉시 파괴합니다. 점수·콤보를 올리는 판정은 아닙니다.
